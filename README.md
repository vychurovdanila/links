# Links

**AI-ассистент для управления связями и договорённостями.**

Links — это визуальная карта ваших контактов, которая помогает не забывать, кому и что вы обещали.
В основе лежит граф связей, где в центре находитесь вы, а вокруг — люди, сгруппированные по слоям (Работа, Семья, Проекты).

## 🧠 Как это работает
1. **Импорт:** Выгружаете JSON из Telegram Desktop.
2. **Анализ ИИ:** Нейросеть находит в переписках договорённости и дедлайны.
3. **Визуализация:** Строится граф, где просроченные задачи подсвечиваются красным.
4. **Telegram-бот:** Напоминает о важных встречах и присылает готовые шаблоны сообщений.

## 🛠 Технологический стек
- **Frontend:** React (Vite), TypeScript, Tailwind CSS 3.4, React Flow (@xyflow/react).
- **Backend (в разработке):** Python (FastAPI), SQLAlchemy, SQLite/PostgreSQL.
- **AI:** Бесплатные облачные API (Google Gemini Flash, Groq).
- **Интеграции:** Telegram Business API (в планах).

## 🚀 Запуск проекта (Frontend)
```bash
npm install
npm run dev
```

## 📁 Структура проекта
- `BRIEF.md` — концепция и бизнес-требования.
- `STATE.md` — текущий статус и планы.
- `TASKS.md` — очередь задач.
- `AGENTS.md` — роли в команде.
- `src/` — исходный код приложения.

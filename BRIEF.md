# BRIEF.md — networkmap (Makefab)

## Что делаем
AI-ассистент по управлению отношениями (AI-driven CRM) в виде визуального графа. 
Приложение парсит выгрузку из Telegram, находит договорённости с помощью 
нейросети, группирует контакты по слоям (проекты, семья, работа) и напоминает 
о важных задачах через Telegram-бота.

## Для кого
Владелец бизнеса / руководитель (B2C SaaS). Человек с большим количеством 
контактов (100-1000), который забывает, кому и что обещал. MVP делаем для 
Данилы, но архитектуру закладываем под будущий продукт для внешних пользователей.

## Ключевые сценарии (User Flow)
1. **Онбординг:** Пользователь делает экспорт Telegram Desktop (JSON) и загружает 
   в приложение. Нейросеть (через облачные API) анализирует переписки.
2. **Главный экран (Карта):** В центре — пользователь. Вокруг — группы (слои): 
   «Семья», «Работа», «Проект Альфа». Внутри групп — люди (узлы).
3. **Договорённости:** ИИ вычленяет из чатов обещания («скину отчет завтра»), 
   вешает их на узлы людей. Просроченные дедлайны подсвечиваются красным.
4. **Действие:** Клик на договорённость -> переход в оригинальный чат Telegram 
   с копированием контекста в буфер обмена (умный переход).
5. **Песочница:** Создание временной группы для симуляции проекта.
6. **Уведомления:** Telegram-бот присылает напоминания о дедлайнах.

## Стек (стандарт Makefab)
- **Frontend:** React (Vite) + TypeScript + Tailwind CSS (строго 3.4) + React Flow (@xyflow/react).
- **Backend (Фаза 2):** Python (FastAPI) + SQLAlchemy + SQLite (dev) / PostgreSQL (prod).
- **AI (Фаза 1):** Бесплатные API (Google Gemini Flash, Groq).
- **Интеграция:** Telegram Business API (для будущей синхронизации).

## Монетизация (Кредитная модель)
- Триал с бесплатным пакетом токенов на первичный анализ.
- Базовая подписка + Пакеты токенов на случай перерасхода.

## Критерии приёмки MVP (Фаза 1 - Фронтенд)

- [ ] Tailwind CSS установлен (версия 3.4.1), настроен.

- [ ] Созданы базовые компоненты: главный холст, узлы групп, узлы людей.
